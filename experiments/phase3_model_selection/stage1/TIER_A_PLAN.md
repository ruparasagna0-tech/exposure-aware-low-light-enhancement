## Checkpoint / resume procedure
- Run folder per model on Drive: `experiments/phase3_model_selection/stage1/runs/tierA_<model>_s42/` with
  `checkpoints/last.pth` (every epoch, atomic write), `checkpoints/best.pth` (on validation improvement),
  `history.json`, `logs/` (run info, pip freeze, integrity checks, one `session_<time>.json` per Colab session),
  `RUN_LABEL.json`, and `logs/train_summary.json` at the end.
- After a stop or disconnect: re-run cells 1–4, then the same model cell. It detects `last.pth` and resumes from the
  last completed epoch; the trainer refuses a resume if the config changed (config MD5) and regenerates the identical
  batch stream per epoch. A completed model (50 epochs, 5,600 steps, not a pipeline test) is never retrained.
